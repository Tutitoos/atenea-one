# Política de seguridad

El proyecto está en fase inicial y no está auditado: no es apto para datos sensibles.

Paquete para el auditor externo: [índice, alcance y evidencia](docs/audit/README.md).

## Reportar una vulnerabilidad

Usa el reporte privado de GitHub: pestaña **Security → Report a vulnerability** de este repositorio. No abras issues ni PRs públicos con detalles de vulnerabilidades, claves, tokens ni capturas reales.

Incluye versión o commit, pasos para reproducir e impacto esperado. Se acusará recibo y se coordinará la divulgación antes de publicar el arreglo.

## Alcance

Protocolo, criptografía, agente, relay, coordinator, control plane y panel. Fuera de alcance: despliegues de terceros y ataques que requieran control previo del host.
